КАТЕГОРИЯ: ОСНОВНОЙ КОД (ОБЯЗАТЕЛЬНО!)
─────────────────────────────────────────────

1. ✅ main.py
   Что: Главный файл для запуска
   Размер: ~400 строк
   Обязательный: ДА
   → Запускается на Render
   → Интегрирует scheduler и keep-alive
   → Точка входа всего приложения

2. ✅ auto_bump_scheduler.py
   Что: Scheduler для автоматического поднятия лотов
   Размер: ~300 строк
   Обязательный: ДА
   → Основная логика поднятия лотов
   → Асинхронный scheduler
   → Автоматическое восстановление при ошибках

3. ✅ keep_alive.py
   Что: Keep-alive для предотвращения выключения на Render
   Размер: ~250 строк
   Обязательный: ДА
   → Пингует каждые 10 минут
   → Генерирует активность
   → Предотвращает spin-down на Render

4. ✅ requirements.txt
   Что: Зависимости Python
   Размер: ~30 строк
   Обязательный: ДА
   → Render использует это для установки пакетов
   → Должен содержать все нужные пакеты
   → Содержит asyncio, aiohttp, python-telegram-bot и т.д.

5. ✅ Procfile
   Что: Конфигурация для Render
   Размер: 1 строка
   Обязательный: ДА (для Render)
   → Указывает Render как запустить приложение
   → Содержит: web: python main.py

6. ✅ .gitignore
   Что: Файлы которые не загружать на GitHub
   Размер: ~50 строк
   Обязательный: ДА
   → Исключает __pycache__, .env, logs, etc
   → Защищает приватные данные

7. ✅ .env.example
   Что: Пример переменных окружения

================================================================================
ПОРЯДОК ЗАГРУЗКИ НА GITHUB
================================================================================

1. Создай репо на GitHub (пустой)
2. Клонируй его к себе: git clone https://...
3. Скопируй ВСЕ ФАЙЛЫ в папку репо
4. Добавь в Git: git add .
5. Коммитни: git commit -m "Initial commit: FunPay Cardinal with Auto-Bump"
6. Загрузи: git push -u origin main

ИЛИ используй веб-интерфейс GitHub:
1. Открой репо на GitHub
2. Add file → Upload files
3. Перетащи все файлы
4. Commit


================================================================================
ПОРЯДОК РАЗВЕРТЫВАНИЯ НА RENDER
================================================================================

1. Создай аккаунт на Render.com
2. New → Web Service
3. Connect GitHub репо
4. Выбери этот репо
5. Fill settings:
   - Build: pip install -r requirements.txt
   - Start: python main.py
6. Add Environment Variables (7 штук)
7. Create Service
8. Жди 2-3 минуты
9. Проверь логи
10. Готово! ✅
